# Feuch Game

Prototype Cloudflare Worker + Durable Objects + WebSockets. Salon par code, présence synchronisée et attribution privée de cinq rôles.

## Local

`npm install && npm run dev`

## Déploiement

`npx wrangler login && npm run deploy`
